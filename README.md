# More Golden Foods - Minecraft Java Mod (Fabric)
More Golden Foods (MGF) is a mod that adds 9 new food items with similar functionality to Golden Apples!

## Featuring...
- 9 whole new food items, including
  
  - Golden Chicken
  - Golden Steak
  - Golden Porkchop
  - Golden Mutton
  - Golden Rabbit
  - Golden Bread
  - Golden Cookie
  - Golden Pumpkin Pie
  - Golden Cake

- Absorption and Regeneration effects upon consumption, with different amplifiers and durations depending on the food
- Ability to craft all food items
- The ability to eat all golden food variants at any time, just like Golden Apples!

## Installation
1. Install the <a href=https://fabricmc.net/use/installer/>Fabric Loader</a> and <a href=https://modrinth.com/mod/fabric-api>API</a>
2. Install the latest version of MGF on <a href=https://modrinth.com/mod/mgf>Modrinth</a>
3. Place the `.jar` file into your mods folder
   - `%appdata%/.minecraft/mods` on Windows
   - `~/Library/Application Support/minecraft/mods` on MacOS
   - `~/.minecraft/mods` on Linux
4. Launch Minecraft and select the Fabric profile
5. Enjoy! :)
